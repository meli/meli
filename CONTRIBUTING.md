# Contributing to meli

**Thank you for your interest in contributing to meli!**

## License

New code should be licensed as `EUPL-1.2 OR GPL-3.0-or-later`.

## Contribution Terms

When making a contribution you agree to the following terms:

- I understand these changes in full and will be able to respond to review comments.
- I have read the [Developer Certificate of Origin](https://developercertificate.org/) and certify my contribution under its conditions.

## AI Policy

Meli does not accept contributions generated by LLMs ([Large Language Models](https://en.wikipedia.org/wiki/Large_language_model)), sometimes also referred to as "AI".

Any content submitted that is clearly labelled as LLM-generated (including issues, pull requests, and pull request descriptions) might be immediately closed.

## Chat

Say hello on `#meli` on OFTC IRC, or, [`#meli:matrix.org`](https://matrix.to/#/#meli:matrix.org) Matrix bridge.

## Pull requests

Meli accepts pull requests in meli's forge: <https://git.meli-email.org/meli/meli>.

See [`DEVELOPMENT.md`](DEVELOPMENT.md) for guidelines.
